# Product Context: Apartment Cost Analyzer

## Purpose

To help users make informed decisions when choosing apartments by:

- Comparing total costs across different rental options
- Breaking down one-time vs recurring expenses
- Visualizing affordability over time

## User Problems Solved

- Difficulty comparing total costs when moving expenses vary
- Lack of visibility into long-term affordability
- Challenges budgeting for all associated costs (security deposits, utilities, etc.)

## Key User Flows

1. Input apartment cost details:

   - Immediate costs (security deposit, moving fees)
   - Monthly expenses (rent, utilities)
   - Personal financial situation (income, savings)

2. View comprehensive cost analysis:

   - Total first-month costs
   - Monthly affordability
   - Long-term projections

3. Compare different scenarios:
   - Multiple apartment options
   - Different lease terms
   - Various financial situations

## Experience Goals

- Clear, guided data entry
- Instant, visual feedback
- Actionable insights
- Easy scenario comparison
